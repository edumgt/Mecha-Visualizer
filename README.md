# NERV CYBER HYPERCAR // EVA-01 SUPERCAR 3D VISUALIZER

> **초정밀 3D Three.js 사이버 하이퍼카 & 에반게리온 바이오메카 전술 비주얼라이저**  
> 고회전 V12 트윈터보 엔진 사운드, 버터플라이 시저 도어, 카본 파이버 에어로다이내믹스, 실시간 Web Audio 및 절차적 발광 전술 바닥 격자가 융합된 차세대 3D 쇼룸.

---

## 🏎️ 주요 기능 및 전면 개편 내역 (Overhaul Highlights)

### 1. 외관 형상 및 에어로다이내믹스 전면 개편 (Body & Shape Overhaul)
- **샤크 노즈(Shark-Nose) & S-덕트**: 날렵하게 떨어지는 쐐기형 프론트 노즈와 냉각 효율을 극대화하는 보닛 중앙 공기 배출구.
- **카본 파이버 에어로 스플리터 & 4단 카나드**: 레이스 트랙 다운포스를 생성하는 프론트 립 및 다이브 플레인.
- **와이드 바디 펜더 & 릴리프 길(Gills)**: 전면 휠 하우스의 와류를 억제하는 상단 카본 루버 에어덕트.
- **스완넥(Swan-Neck) 탑마운트 GT 리어 윙**: 다운포스 받음각을 가진 3D 에어포일과 대형 엔드플레이트.
- **6단 벤트리 디퓨저 & 티타늄 쿼드 머플러**: 차량 하부 공기를 고속 방출하는 대형 디퓨저 핀 및 4구 티타늄 배기 테일파이프.
- **버터플라이 / 시저 도어 (Scissor Doors)**: 상단 대각선 방향으로 오픈되는 유압식 도어 애니메이션.

### 2. 하이엔드 CMF(Color, Material, Finish) 질감 개편 (Materials & Textures)
- **클리어코트 멀티레이어 자동차 도료 (MeshPhysicalMaterial)**:
  - 거울처럼 투명한 2중 클리어코트 레이어(`clearcoat: 1.0`, `clearcoatRoughness: 0.04`).
  - 높은 반사율과 굴절률(IOR 1.58)을 적용한 오토모티브 하이글로스 페인트.
- **2x2 트윌 직조 카본 파이버 (Carbon Fiber)**:
  - 범프 맵으로 직조 질감을 살린 초경량 복합재 스플리터, 루프 스파인, 사이드 인테이크, 리어 디퓨저.
- **타공 카본 세라믹 브레이크 & 모노블록 캘리퍼**:
  - 나선형 벤틸레이션 홀이 정밀 가공된 브레이크 로터 디스크와 브렘보(Brembo) 레이싱 캘리퍼.
- **비대칭 퍼포먼스 타이어 트레드 (Performance Tires)**:
  - 4열 배수 그루브와 숄더 블록이 양각으로 렌더링된 초광폭 로우프로파일 컴파운드 타이어.
- **사이버 광학 조명 (Continuous Cyber Lighting)**:
  - 트리플 LED 프로젝터 헤드램프, 엔젤윙 DRL, 후면 일체형 네온 테일램프 바 및 네온 언더글로우(Underglow).

### 3. 에바 테마 5종 외장 컬러 / 리버리 (Liveries & Themes)
1. **초호기 바이올렛 V12 (Shinji Special)**: 메탈릭 이리스 딥 퍼플 바디 + 네온 라임그린 브렘보 캘리퍼 & 형광 스트라이프.
2. **2호기 로쏘 코르사 (Asuka Scuderia)**: 이탈리안 로쏘 코르사 레드 래커 + 탠저린 오렌지 에어로 핀 & 단조 골드 레이스 휠.
3. **0호기 알핀 블루 (Rei Prototype)**: 코발트 펄 블루 바디 + 세라믹 화이트 악센트 & 폴리싱 미러 실버 림.
4. **폭주 흑요석 비스트 (Berserk Beast)**: 사틴 팬텀 옵시디언 다크 카본 + 핏빛 크림슨 레드 광학 빔.
5. **우주 결전형 하이퍼카 (Space Combat Edition)**: 펄 바이올렛 바디 + 일렉트릭 시안 네온 & 건메탈 티타늄 휠.

### 4. 100% 절차적 실시간 사운드 신시사이저 (Web Audio Synthesis)
- **V12 트윈터보 고회전 배기음 (Engine Rev-Up)**: 다기통 사운드 배기음 실시간 합성 (단축키 `[E]`).
- **블로우오프 밸브(BOV) & 니트로 부스터**: 압축 공기 방출 휘슬음 및 후면 배기 화염 연출 (단축키 `[N]`).
- **시저 도어 유압 공압음**: 도어 개폐 시의 정밀한 액추에이터 사운드 (단축키 `[O]`).
- **격납고 앰비언스 사운드**: 55Hz 저주파 웅웅거림, 공조 시스템 및 주기적 유압 피스톤 배기음.

## ⌨️ 단축키 안내 (Keyboard Controls)

| 키 | 동작 | 설명 |
|---|---|---|
| **[M]** | 모드 전환 | 스포츠카 ↔ 로봇 메카 모드 즉시 전환 |
| **[O]** | 시저 도어 | 버터플라이 시저 도어 개폐 |
| **[E]** | V12 가속 | 트윈터보 고회전 배기음 격발 & 휠 스핀 |
| **[N]** | 니트로 | 니트로 부스터 배기 불꽃 & 터보 블로우오프 밸브 |
| **[1]** | 우주 결전 하이퍼카 | 시안 / 바이올렛 리버리 |
| **[2]** | 2호기 로쏘 코르사 | 스쿠데리아 레드 / 골드 휠 |
| **[0]** | 0호기 알핀 블루 | 코발트 펄 / 실버 휠 |
| **[B]** | 폭주 비스트 | 다크 흑요석 카본 / 크림슨 레드 |
| **[G]** | 전술 바닥 격자 | 절차적 발광 전술 바닥 HUD 격자 ON/OFF |
| **[L]** | 레이저 스캔 | NERV 격납고 3D 진단 레이저 스캔라인 ON/OFF |
| **[D]** | 피격 충격 | 화면 글리치 및 카메라 셰이크 시뮬레이션 |
| **[V]** | 영상 레퍼런스 | 우주 결전 영상 레퍼런스 모달 플레이어 |
| **마우스 드래그** | 360° 회전 | OrbitControls 자유 궤도 카메라 탐색 |

## 🛠️ 기술 스택 (Tech Stack)

- **Engine & Graphics**: Three.js (r128+), WebGL2, GLSL Custom Shaders
- **Framework**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Audio**: Web Audio API (No external audio files, 100% procedural sound synthesis)
